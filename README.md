# Proyecto Final · Sistemas Operativos 750001C

**Grupo 06** · Universidad del Valle sede Yumbo · Semestre 2026-2

Este es el repositorio oficial del proyecto final. Aquí se documenta el proceso de montaje de dos máquinas virtuales con Linux, la publicación de una imagen de Docker Hub, el despliegue de Kubernetes y el sitio web con las evidencias.

## Objetivo

Montar dos máquinas virtuales con Linux en VirtualBox, configurarlas, publicas en Docker Hub una imagen propia, desplegarla en Kubernetes y contar lo que hicimos en este sitio.
